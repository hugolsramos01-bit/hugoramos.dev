O **DataFrota** é uma iniciativa de engenharia de dados e software voltada à consolidação de informações operacionais de frota em uma base única para consulta, auditoria e análise.

O projeto combina ingestão de dados de diferentes fontes, histórico, regras de qualidade, APIs e interfaces para transformar registros operacionais em informação utilizável por equipes de gestão.

## Minha atuação

- desenvolvimento de pipelines históricos e incrementais em **Python**;
- consolidação e deduplicação de milhões de registros operacionais;
- modelagem e camadas de consumo em **PostgreSQL**;
- desenvolvimento de APIs e aplicação web para consulta de veículos e eventos;
- integração com Power BI e regras de acesso por unidade gestora;
- documentação, auditoria e rastreabilidade das cargas.

## Princípio de arquitetura

A camada analítica não substitui as fontes originais. Ela organiza, reconcilia e documenta os dados para permitir uso consistente por aplicações, relatórios e processos de auditoria.
